# Sulala Agent OS v1.0.0

First stable release of **Sulala** — a lightweight, Bun-based Agent Operating System for graph-based, collaborative micro-agents.

## Highlights

- **Multi-agent workflows** — Agents collaborate in graphs instead of a single-agent loop
- **Skills & marketplace** — Install and configure skills from the dashboard; skills are defined by SKILL.md and optional scripts
- **Web dashboard** — Manage agents, chat, graphs, skills, schedules, and memory at `http://127.0.0.1:3010`
- **Channels** — Connect via Telegram, Slack, Discord, Signal, or Viber
- **CLI** — `sulala start`, `sulala run <agent> <task>`, `sulala onboard`, `sulala dashboard-token`, and more
- **Lightweight runtime** — Core stays ~100–150 KB; with dependencies, sub‑MB scale
- **External AI providers** — OpenAI, Anthropic, OpenRouter, Google; API keys in dashboard or env

## Install

```bash
bun add -g @sulala-ai/agent-os
# or: curl -fsSL https://sulala.ai/install.sh | bash
```

Then run `sulala onboard` to create config, seed agents, and open the dashboard.
